# local-skill-emergency-hotline

## Description
Local Skill Emergency Hotline is an app that helps people quickly find local skilled helpers during emergencies. The app connects users with people who have useful skills and can provide assistance when needed.

## Problem
During emergencies, people may not know who to contact for quick help. This app helps make finding local support easier and faster.

## Planned Features
- Find local helpers based on skills
- Emergency contact system
- User-friendly interface
- Search for available assistance nearby
